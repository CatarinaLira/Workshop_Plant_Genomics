# I Workshop de Genômica de Plantas (2026)
**Genômica Populacional, Marcadores NGS e Ferramentas Bioinformáticas Aplicadas à Flora Nativa**

Workshop realizado nos dias 31/08/2026 a 4/09/2026

Projeto Pensa Rio / FAPERJ

## 📁 Estrutura do Repositório
- `/scripts/01_bioinfo`: Scripts em Bash/Linux para qualidade de leituras e execução do Stacks v2.68.
- `/scripts/02_r_stats`: Scripts em R para importação de VCF, PCA, DAPC e índices de genética de populações.
- `/scripts/03_catGenes`: Scripts em R para pacote catGenes: mineração de sequências, alinhamentos, análises filogenéticas.
- `/Documentos`: Cronograma e Guias Preparatórios do curso.
